# Simple-Weather-Apps
A series of simple weather applications on Django through the OpenWeatherApp or any other apis, based on a [simple weather app tutorial](https://webdesign.tutsplus.com/build-a-simple-weather-app-with-vanilla-javascript--cms-33893t).

This project is purposed solely for web development practice, frontend and backend.
REQUIRES AN OPEN_WEATHER API KEY IN YOUR `.env` file.

To run the server:
```
python .\manage.py runserver 
```

More features and endpoints will be considered and implemented.
